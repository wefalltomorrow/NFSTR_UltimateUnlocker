# NFSTR Ultimate Unlocker v1.1.0

This version adds an INI so you can choose between unlocking just the old DLC content or unlocking everything.

## Default setup

```ini
[UNLOCKS]
UnlockDLC = 1
UnlockAll = 0
```

With the defaults, the old DLC/preorder/promo content is enabled but normal career, level and challenge progression still works.

## Options

- `UnlockDLC=1` - enables the old DLC, preorder and promo content that no longer unlocks normally.
- `UnlockAll=1` - enables the original full Ultimate Unlocker behavior, including Time Savers, cars, challenges and stage select.

## Install

Put these files in the folder used by your ASI loader:

- `NFSTR_UltimateUnlocker.asi`
- `NFSTR_UltimateUnlocker.ini`

Built for the DRM-free Need for Speed: The Run v1.1.0.0 PC executable.
